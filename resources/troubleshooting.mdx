## Setup and bot issues

### Kao did not detect the hosted bot

**Symptoms**

- After you approve the Discord invite, Kao does not show **Kao joined this server.**

**Fixes**

1. Make sure you finished the invite in Discord and selected the same server.
2. If the Discord window closed early, click **Reopen Discord** and approve the invite.
3. If Kao is already in the server, click **I've already invited Kao**.
4. If Discord does not list the server, ask a server admin for **Manage Server** or to invite Kao.

### Bot permission warning or bot not found

**Symptoms**

- Kao says the bot is missing permissions.
- Kao says it cannot check the bot because it is offline or still starting.
- The server appears under **Needs attention**.

**Fixes**

1. Open the warning to see which permission or feature is affected.
2. Click **Update in Discord** if it appears, and approve the permissions.
3. If the bot was removed, click **Invite again**.
4. If your own bot is starting, wait a minute and let Kao check again.
5. Check the [Kao status page](https://status.usekao.com) if the check stays unavailable.

### BYOB bot will not connect

**Symptoms**

- Kao rejects the token.
- Your bot goes offline after a token reset.
- Kao warns that **Server Members Intent** is turned off.

**Fixes**

1. Open the [Discord Developer Portal](https://discord.com/developers/applications) and select your application.
2. Open **Bot** and make sure **Server Members Intent** is on.
3. Click **Reset Token** and copy the new token.
4. In Kao, open the bot and click **Update token**.

<Warning>
Resetting a token stops the old token immediately. Update it in Kao right away.
</Warning>

### Server does not appear

**Symptoms**

- A server is missing from a server picker.

**Fixes**

1. Check that Kao is in the server on the **Servers** page.
2. If someone else manages the server, ask them to add you to its team role.
3. If you just invited a bot, refresh the page.
4. Sign out and back in to refresh your Discord server list.

### Server shows Paused

**Symptoms**

- A hosted Kao Bot server shows **Paused**.

**Fixes**

Your plan allows fewer hosted servers than you have. On Free, the limit is 2. Remove a hosted server, or upgrade to resume it. Nothing in the server was deleted.

## Discord command issues

### /kao does not appear

**Fixes**

1. Restart Discord or press `Ctrl+R` (`Cmd+R` on Mac) to refresh it.
2. Check that Kao is in the server.
3. On the server's **Overview** in Kao, click **Update in Discord** if it appears.

### "You need a Kao role to use Kao here."

**Fixes**

Ask a Kao administrator to give you a Kao role on the server's **Commands** page. You also need the matching Discord permission, such as **Create Expressions** to import. See [Kao roles](/guides/server-settings#kao-roles).

## Import issues

### Server is full

**Symptoms**

- Imports, restores, rotations, or syncs fail because the server has no free slots.

**Fixes**

1. Delete unused emojis on the **Emotes** page.
2. Choose a different server.
3. Import fewer emotes.
4. Boost the server for more slots. See [Discord limits](/concepts/overview#discord-limits).

### Bot is missing Create Expressions

**Symptoms**

- Kao shows "Bot is missing Create Expressions".
- Adding, renaming, or deleting emojis fails.

**Fixes**

1. On the server's **Overview** in Kao, click **Update in Discord** if it appears.
2. Otherwise, open the server's role settings in Discord.
3. Give the bot's role **Create Expressions** and **Manage Expressions**.

### Import is waiting

**Symptoms**

- An import shows **Waiting**.
- A large batch takes a long time.

**Fixes**

1. Check **Activity** for the reason and estimated finish time.
2. If it says "Waiting for Discord's hourly emoji limit", wait. Each server can take about 50 new emojis an hour.
3. If it says "Waiting for your daily import limit to reset", wait until tomorrow or upgrade.
4. Animated emotes may take longer while Kao prepares them.

### An emote looks cropped or too small

**Fixes**

1. Check the Discord-size previews before importing.
2. Choose **Fit** if important edges are cropped.
3. Choose **Trim** to remove empty space.
4. Set your usual choice in **Settings** > **Import defaults**.

### Search returns no results

**Fixes**

1. Try a shorter search term.
2. Switch **Source** between 7TV and FrankerFaceZ.
3. For 7TV, search by tag, such as `#cat`, or search on the **Users** tab and browse the creator's sets.
4. BetterTTV and EmojiGG search is no longer available.
5. If 7TV is having problems, Kao shows a notice. Try again later.

## Automation issues

### Rotation or sync removed emojis I wanted

**Fixes**

1. Restore the emojis from a backup, if you have one.
2. Protect emojis you always want to keep. See [Protect emojis](/guides/managing-emojis#protect-emojis).
3. For sync groups, consider turning off **Remove Extra Emojis**.

### Rotation did not run

**Fixes**

1. Check that the rotation is turned on.
2. If it shows **Paused by plan**, your plan does not include it. Upgrade to resume it.
3. If it shows "Waiting for new emotes", it runs after the streamer adds more emotes.

### Streamer follow is paused

**Fixes**

Open the streamer's panel and follow the reason shown. Kao resumes the follow automatically after you fix it.

## Dashboard issues

### Buttons or pages do not respond

**Fixes**

1. Refresh the page.
2. Sign out and back in.
3. Try a private browser window.
4. Turn off extensions that block scripts or pop-ups.
5. Try another browser.

### The Discord invite does not open

**Fixes**

1. Allow pop-ups for usekao.com.
2. Click the invite button again.
3. On a phone, Discord may open in the app. Approve the invite there, then return to Kao.

## Billing issues

### Plan did not activate

**Fixes**

1. Refresh the **Billing** page.
2. For crypto, wait until NowPayments confirms the payment.
3. If the crypto invoice expired, start a new checkout.
4. If you paid with crypto while a card subscription was active, support reviews the payment first.
5. Contact support if the plan stays inactive after the payment is confirmed.

### Coupon did not apply

**Fixes**

1. Enter the coupon again and click **Apply**.
2. Check that the coupon covers the plan, billing interval, and payment method.
3. Start checkout again from Kao.

## Sign-in issues

### Cannot sign in with Discord

**Fixes**

1. Clear cookies for usekao.com.
2. Try another browser.
3. Check [Discord's status page](https://discordstatus.com).
4. Sign in again from [usekao.com](https://usekao.com).

### Account is locked after requesting deletion

Your account is locked during the 14-day deletion period. To keep your account, open the deletion status page and click **Cancel deletion**. See [Account and privacy](/guides/account-management#cancel-or-check-a-deletion).

## Getting more help

When you contact support, include what you were trying to do, the exact error message, and which server was affected.
