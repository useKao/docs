## Start with the docs

Use the [FAQ](/resources/faq) for short answers and [Troubleshooting](/resources/troubleshooting) when something is not working. The [Quickstart](/quickstart) is the fastest path for a first hosted Kao Bot setup.

## Check service status

Check the [Kao service status page](https://status.usekao.com) before retrying an action that fails across multiple servers or pages. It shows whether Kao is operational, degraded, under maintenance, or experiencing downtime.

## Get account-specific help

If you are signed in, open **Support** from the dashboard. The authenticated support desk can guide you using your current setup, accessible servers, recent activity, and service status.

Use the public docs and [Help Center](https://usekao.com/help) when you are not signed in or want a general answer that applies to any Kao account.

## Contact Kao

| Channel | Use it for |
|---------|-------------|
| [Kao documentation](https://docs.usekao.com) | Setup steps, feature guides, and common answers |
| [Kao Discord server](https://usekao.com/api/discord/invite) | Community help and product discussion |
| [Email support](mailto:support@usekao.com) | Account-specific questions or private details |
| [Report an issue](https://usekao.com/report) | A reproducible bug or broken product flow |

When you contact support, include:

- What you were trying to do
- The exact error message
- Which server or workflow was affected
- What you already tried
- A screenshot when it helps explain the problem

Do not send your Discord or BYOB bot token in a support request.
