## General

### What is Kao?

Kao is a Discord emoji management platform. It helps you import emotes from 7TV, BetterTTV, FrankerFaceZ, EmojiGG, and Discord emote text or URLs, then manage them from one dashboard.

### Is Kao free?

Kao has a free tier and paid plans. Paid plans unlock higher limits and advanced features such as more backups, rotations, sync groups, collections, bots, or servers.

### Do I need to create my own Discord bot?

No. Most users can invite the hosted Kao Bot and start from the dashboard.

You only need to create your own bot if you choose Bring Your Own Bot for custom identity, custom status, or stricter separation between communities.

### Which emote sources are supported?

Kao supports:

- 7TV
- BetterTTV
- FrankerFaceZ
- EmojiGG
- Discord emote text or URLs pasted into the import tool

## Setup

### What Discord permissions does Kao need?

Kao needs enough Discord access to identify your account, list eligible servers, and manage emojis through the bot you install.

The bot needs **Manage Emojis and Stickers** in each server where Kao will add, rename, delete, restore, rotate, or sync emojis.

### Why can I not invite the hosted bot?

You may not have permission to manage or invite apps to that server. Ask a server administrator to invite Kao or update your Discord role.

### Can I use my own bot?

Yes. Use Bring Your Own Bot from the **Bots** page when you want a custom bot name, avatar, status, or separate bot identity.

### Can I use the same BYOB bot for multiple servers?

Yes. Invite the bot to each server, then assign those servers in Kao.

## Imports and emojis

### How many emojis can I import?

Kao plan limits control daily imports. Discord server capacity also controls how many emojis the target server can store.

| Server boost level | Static emojis | Animated emojis |
|--------------------|---------------|-----------------|
| No boost | 50 | 50 |
| Level 1 | 100 | 100 |
| Level 2 | 150 | 150 |
| Level 3 | 250 | 250 |

### Can I import animated emotes?

Yes, when the source provides a valid animated file and the target server has animated emoji capacity.

### Why did an import fail?

Common causes include:

- Server emoji capacity is full
- Bot permission is missing
- Emoji name is invalid or already used
- Source file is unavailable or invalid
- Discord is temporarily limiting emoji changes

### Can I rename or delete emojis after importing?

Yes. Use the server emoji view to rename or delete emojis individually or in bulk.

## Collections, backups, rotations, and sync

### What are collections?

Collections are reusable groups of emotes. Use them for bulk imports, rotations, sync groups, or personal curation.

### What are backups?

Backups are point-in-time snapshots of a server's emojis. Use them before large changes or to restore/copy emojis later.

### How do rotations work?

Rotations refresh a server's emojis from one or more collections on a schedule or when you run them manually.

### What are sync groups?

Sync groups copy emojis from a collection or source server to one or more target servers.

## Account and billing

### How do I sign in?

Sign in with Discord from [usekao.com](https://usekao.com).

### What payment methods are accepted?

Kao supports card payments through Stripe and crypto payments through NowPayments.

### Can I use coupons with crypto?

Yes. Eligible coupons can discount crypto checkout before the NowPayments invoice is created. Trial-extension coupons, or discount coupons that reduce the payable amount to zero, can activate or extend crypto-plan access without a payable invoice.

### Can I cancel my subscription?

Yes. Cancel from the **Billing** page. Your plan remains active until the end of the current billing period.

### Can I export or delete my account?

Yes. Use the account controls when they are visible in your dashboard. If they are not visible, contact support to request an export or account deletion.

### Can teammates help manage a server?

Yes. Server owners can share access with teammates through role-based server access.
