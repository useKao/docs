## Overview

The **Servers** page lists every server Kao can manage for you and every bot you have connected. Use it to add servers, fix problems, and open a server's own page.

## Servers page sections

| Section | What it shows |
|---------|---------------|
| **Needs attention** | Servers with a problem, such as a removed bot. Offers **Invite again**, **Remove**, or **Dismiss** |
| **Your servers** | Servers you manage, with an **Emoji slots** bar for each |
| **Shared with you** | Servers another Kao user shared with you through a Discord team role |
| **Your bots** | Your connected BYOB bots |

The page header shows how many servers use the hosted Kao Bot out of your plan's limit.

## Add a server

1. Open **Servers** and click **Add server**.
2. Choose **Use the Kao hosted bot** or **Connect your own bot**.
3. Follow the steps to invite the bot in Discord.
4. Return to Kao and wait for verification to finish.

See [Choose a bot setup](/concepts/bot-system) if you are not sure which option to choose.

## Connect your own bot

Each BYOB bot needs its own Discord application and token. Follow [Create a BYOB bot](/concepts/bot-system#create-a-byob-bot) first.

1. Open **Servers**. Click **Connect a bot** under **Your bots**, or choose **Connect your own bot** from **Add server**.
2. Paste the bot token and let Kao check it.
3. Invite the bot to the servers it should manage.

Kao rechecks the bot's server list when you return from Discord.

## Manage a connected bot

Open a bot from **Your bots** to see its page. From there you can:

- Review which servers the bot is in and their permission health.
- Use **Unlink Server** to stop managing a server with this bot.
- Use **Update token** after you reset the token in Discord.
- Set a custom status in the **Bot Status** card, if your plan includes custom bot status.

<Warning>
Resetting a token in Discord stops the old token immediately. Update the token in Kao right away, or the bot goes offline.
</Warning>

## Shared servers

A server owner can share a server with teammates through a Discord role. Members with that role see the server under **Shared with you**.

Teammates can manage a shared server from their own dashboard. Some actions, such as running polls, also depend on their Kao role and Discord permissions. See [Team access](/guides/server-settings#team-access).

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| Bot will not connect | The token is wrong, or **Server Members Intent** is off | Reset the token, turn on the intent, and paste the new token |
| Server is missing | The bot is not in that server, or it was not shared with you | Invite the bot, or ask the owner to add you to the team role |
| Server shows **Paused** | Your plan's hosted server limit is lower than your server count | Remove a hosted server or upgrade your plan |
| Server is under **Needs attention** | The bot was removed or lost permissions | Use **Invite again** or the offered fix |
| Permission check is unavailable | Your bot is offline or still starting | Wait for it to come online, then check again |
