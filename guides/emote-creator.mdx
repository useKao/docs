## Overview

The Emote Creator lets you combine a base emote with overlays, effects, and templates. You can preview the result, save it to your creations gallery, then import it into a server or download it.

## Start a creation

1. Go to **Create**.
2. Add a base layer or choose a template.
3. Add overlays.
4. Position each layer on the canvas.

The canvas uses a transparent background preview so you can see what will become transparent in Discord.

## Work with layers

Each layer can be adjusted independently:

| Control | What it changes |
|---------|-----------------|
| Position | Where the layer sits on the canvas |
| Scale | How large the layer appears |
| Rotation | The layer angle |
| Opacity | How transparent the layer is |
| Order | Which layers appear in front |

Use the layer panel to select, reorder, or remove layers.

## Use templates and quick overlays

Templates give you a starting point. Quick overlays are useful for common additions such as hats, glasses, effects, and other decorative layers.

After applying a template or overlay, you can still move and adjust each layer.

## Preview before saving

Discord often displays emojis at small sizes. Before saving:

1. Open the preview.
2. Check the emote at smaller sizes.
3. Remove tiny details that are hard to read.
4. Increase contrast when the result feels muddy.

<Info>
Simple, high-contrast compositions usually work better than detailed images once Discord shrinks them.
</Info>

## Save and use your creation

1. Choose **Save**.
2. Open the creation from your gallery.
3. Import it to a server, download it, or delete it when you no longer need it.

Created emotes follow the same server capacity and naming rules as imported emotes.

## Troubleshooting

| Problem | What to try |
|---------|-------------|
| Emote looks unclear | Preview at small size and simplify layers |
| Overlay is hidden | Move it higher in the layer order |
| Import fails | Check server capacity, bot permissions, and emoji name |
| You want to reuse it later | Keep it in your creations gallery or download it |
