## Overview

Rotations change a server's emojis automatically using emotes from your collections. Use them for seasonal sets, event emojis, or a server that always has something new.

A rotation makes real changes in Discord. Free slots, file processing, and Discord's hourly limit can delay completion, so check the run result rather than the scheduled time.

## Before you begin

- Rotations need a paid plan. Pro includes up to 15 rotations, with runs as often as every 2 hours.
- Kao must be in the server with **Create Expressions** and **Manage Expressions**.
- You need at least one [collection](/guides/collections) with emotes.
- [Protect](/guides/managing-emojis#protect-emojis) any emojis that must stay, and consider a [backup](/guides/backups) first.

## Create a rotation

1. Open **Rotations** and click **Create rotation**.
2. **Basic Information**: enter a **Rotation Name** and choose the **Target Server**.
3. **Select Collection**: choose the source collection.
4. **Schedule Configuration**: choose **When to rotate**, then set the interval and **Timezone**.
5. **Rotation Behavior**: choose how emojis change, and which emotes to pick.
6. **Review and Create**: check your choices and create the rotation.

## When to rotate

| Option | How it works |
|--------|--------------|
| **On a schedule** | Runs at a **Repeat Every** interval, from 1 hour to 1 week. Your plan sets the shortest interval allowed |
| **When the channel adds emotes** | Runs after a followed streamer adds a set number of new emotes (1–50). Needs a collection linked to a [streamer follow](/guides/streamer-emotes) |

## Rotation behavior

| Behavior | What it does | Use it when |
|----------|--------------|-------------|
| **Full Replacement** | Replaces the server's emojis with emotes from the collection | You want a completely new set each run |
| **Partial Update** | Keeps the base emojis you choose and rotates the rest | Some permanent emojis should stay |
| **Playlist Rotation** | Cycles through several collections in order | You want different collections over time |
| **Fresh swap** | Adds the newest emotes and removes the oldest unprotected ones only when the server is full | You follow a streamer and always want their latest emotes |

For **Partial Update**, select the base emojis to keep. For **Playlist Rotation**, select at least two collections.

### Which emotes to pick

Except for **Fresh swap**, choose how Kao picks emotes from the collection: **Random**, **Newest first**, **Favor recent**, or **Added after a date**.

<Warning>
**Full Replacement** can remove many emojis, including ones that are not in the collection. Protected emojis and Discord-managed emojis are never removed. Protect the emojis you want to keep before you turn it on.
</Warning>

## Run a rotation now

Click **Run now** on the rotation's row or page. Kao shows what it will remove and add before you confirm, and offers a link to back up the server first.

A manual run makes real changes. Turning a rotation off later does not bring back emojis an earlier run removed.

Manual and scheduled runs of the same rotation never overlap.

## Manage rotations

The **Rotations** page lists each rotation with its recent runs. Rotations with a problem appear under **Needs attention**.

Open a rotation to see its page:

- **Turn on** or **Turn off** the rotation
- **Run now**
- **Next run**, **Last run**, and how often it repeats
- **Runs**, filtered by **All** or **Problems**
- The rotation's settings
- **Kept on every run**: the emojis Kao will never remove

Delete a rotation from the menu on its page.

## Check that a run finished

Open a run on the rotation's page, or find it in **Activity**. Each run shows which emotes were added or removed and how the run started.

- Check that the run reached a final state.
- If an emote failed, click **Try again** next to it.
- Check that the server has free slots and the bot has permission before retrying.

## When your plan changes

If your plan no longer includes rotations, or you have more than it allows, the extra rotations show **Paused by plan**. Kao keeps them, and they resume if you upgrade.

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| Rotation did not run | It is turned off, or paused by your plan | Turn it on, or check your plan |
| Rotation shows "Waiting for new emotes" | It runs when the streamer adds emotes, and not enough are new yet | Wait for the streamer to add more, or switch to **On a schedule** |
| Run partly finished | The server ran out of slots, or the bot lost permission | Fix the cause, then click **Try again** on failed emotes |
| Emojis you wanted were removed | They were not protected | Protect them, then restore from a backup |
| Target server is missing | Kao is not in the server | Add the server on the **Servers** page |
