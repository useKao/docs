## Overview

Kao can rotate your Discord server emojis automatically on a recurring schedule. Rotations use emotes saved in Kao collections. Use them when you want seasonal sets, event-specific emoji pools, or a server that changes on a schedule.

The schedule starts a real Discord mutation workflow. Capacity, file processing,
and Discord limits can delay completion, so the execution result matters more
than the scheduled start time.

## Before you begin

You need:

- The hosted Kao Bot or your BYOB bot installed in a server Kao can manage
- The bot permission to manage emojis in that server
- At least one collection with emotes
- Enough plan allowance for active rotations
- A backup if the rotation may remove existing emojis

## Create a rotation

1. Go to **Rotations**.
2. Choose **Create Rotation**.
3. Name the rotation and select a server.
4. Choose a collection.
5. Set **Repeat Every** and **Timezone**.
6. Choose the rotation behavior. For a playlist, choose at least two collections at this step.
7. Review and create the rotation.

## Schedule options

| Schedule | Use it when |
|----------|-------------|
| Simple recurring | You want an interval such as every 6, 12, or 24 hours |

Choose an available **Repeat Every** interval and a **Timezone**. The minimum interval depends on your plan; unavailable intervals are disabled. A scheduled start does not promise an exact completion time.

## Rotation behavior

| Behavior | What it does | Use it when |
| --- | --- | --- |
| Full replacement | Removes the server's existing emojis and replaces them with emotes from one collection | You want to replace the current set with one collection |
| Partial update | Keeps the base emojis you choose and rotates the remaining emojis from one collection | Some permanent emojis should stay in place |
| Playlist rotation | Cycles through multiple collections in sequence | You want different collections to appear over time |

When you choose **Partial update**, select the base emojis that should stay on the server. When you choose **Playlist rotation**, select at least two collections.

<Warning>
Full replacement can remove many server emojis, including emojis that are not in the selected collection. Create a backup before enabling it on an important server.
</Warning>

## Run a rotation manually

Use **Execute Now** when you want to test or run a rotation outside its schedule.

Kao shows live progress while it removes and adds emojis. Processing and Discord limits can delay completion. Check execution history for added, removed, and failed items before running it again.

<Warning>
**Execute Now** performs real changes. Test a replacement rotation on a test server first. Disabling a schedule does not restore emojis removed by an earlier execution.
</Warning>

## Manage rotations

From the Rotations page you can:

- Enable or disable a rotation
- Open rotation details
- Run a rotation manually
- View execution history
- Delete a rotation

## How to know a rotation finished

Open rotation history or **Activity** and check:

- The execution reached a final state.
- Added, removed, and failed item counts are visible.
- Base emojis remain after a partial update.
- The expected collection is active after a playlist step.
- The server still has enough capacity and the bot has permission before a retry.

Do not immediately rerun a partial execution. Review failed items first, because
another run can repeat removals without fixing the failed additions.

## Troubleshooting

| Problem | What to check |
|---------|---------------|
| Target server is missing | Confirm the bot is linked to that server, then refresh Rotations so Kao reloads target server capacity |
| Rotation did not run | Make sure it is enabled and the schedule is correct |
| Rotation partially completed | Open history or Activity to see which emojis failed |
| Server is missing emojis | Check capacity, source collection size, and failed items. A partial run may have removed emojis before additions completed; review history before retrying or restoring a backup |
| Plan limit reached | Disable or delete an old rotation, or review your plan |
