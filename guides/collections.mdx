## Overview

Collections are reusable emote sets. Use them to curate themes, save favorites, prepare a server import, power rotations, or sync the same set across multiple servers.

## Create a collection

1. Go to **Collections**.
2. Choose **Create Collection**.
3. Add a name and optional description.
4. Save the collection.

Keep names short and descriptive, such as "Reaction Faces", "Seasonal Emotes", or "Main Community Set".

## Add emotes

You can add emotes from several places:

- Search results on the **Import** page
- Public 7TV sets
- A backup converted into a collection

## Copy a 7TV set

Use 7TV user search when you want to copy a public 7TV set into a collection.

1. Open the collection.
2. Choose **Add Emotes**.
3. Search for a 7TV user.
4. Open the user's public sets.
5. Copy the set into the collection.

<Info>
Copying creates a collection snapshot. Future changes to the 7TV set do not automatically change your collection.
</Info>

## Organize a collection

Inside a collection you can:

- Search and filter emotes
- Mark favorites
- Remove emotes
- Drag to reorder
- Export the collection as JSON

Favorites are useful when importing from a large collection because Kao can prioritize them during selection.

## Import from a collection

1. Open the collection.
2. Choose **Import to Server**.
3. Select the target server.
4. Choose favorites, random, static, or animated selection.
5. Confirm the import.

Progress appears in the import modal, operations dock, and **Activity**.

## Smart select

Smart select helps choose emotes from a collection when you do not want to pick every item manually. Review the suggested selection before importing.

## Use collections with automation

Collections can be used as the source for:

- **Rotations**, which refresh a server on a schedule
- **Sync groups**, which copy a collection to target servers
- **Backups**, when a backup is converted into a reusable collection

## Best practices

- Keep each collection focused on one purpose.
- Use descriptions for context, such as "monthly rotation source".
- Favorite the emotes you want Kao to prefer.
- Remove stale emotes so automation stays predictable.
