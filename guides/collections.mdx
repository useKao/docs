## Overview

Collections are reusable emote sets. Use them to save favorites, prepare a themed import, or feed rotations, syncs, and poll schedules.

Open **Collections** from the **Emotes** area of the sidebar. The page has two sections:

- **Yours**: collections you created.
- **Server collections**: collections shared with a server's authorized staff.

## Before you begin

Your plan sets how many collections you can keep and how many emotes each can hold. On Free, you can keep 2 collections of up to 50 emotes each. See [Billing and plans](/guides/billing#plan-limits).

## Create a collection

1. Open **Collections**.
2. Click **New Collection**.
3. Add a name and an optional description.
4. Save the collection.

Keep names short and descriptive, such as "Reaction Faces" or "Monthly Rotation".

## Add emotes

You can add emotes from:

- Search results on the **Import** page
- A public 7TV emote set
- A backup, with **Add to Collection**

Each emote shows where it came from, such as "Added by you" or the 7TV channel it came from.

## Copy a 7TV set

1. Open the collection.
2. Click **Add Emotes**.
3. Open the **Browse 7TV Users** tab and search for a 7TV user.
4. Open one of their sets.
5. Click **Copy to Collection**.

<Info>
Copying makes a snapshot. Later changes to the 7TV set do not change your collection. To keep a collection matched to a streamer's set, [follow the streamer](/guides/streamer-emotes) instead.
</Info>

## Organize a collection

Inside a collection you can:

- Search and filter emotes
- Mark favorites
- Remove emotes
- Drag emotes to reorder them

## Export a collection

Click **Export** and choose:

- **Emote images (.zip)** to download every emote image
- **Emote list (.json)** to download the list of emotes

## Import from a collection

1. Open the collection.
2. Click **Import to Discord**.
3. Select the target server.
4. Choose how to select emotes: **Import Favorites**, **Random Selection**, **Animated Only**, or **Static Only**.
5. Review the preview and confirm.

Progress appears in the import window, the operations dock, and **Activity**. If the server has no room left this hour, Kao queues the emotes instead of failing.

## Use collections with automation

Collections can be the source for:

- [Rotations](/guides/rotations), which refresh a server on a schedule
- [Sync groups](/guides/sync-groups), which make target servers match the collection
- [Poll schedules](/guides/emote-polls#poll-schedules), which start polls from the collection

Collections linked to a [streamer follow](/guides/streamer-emotes) are managed by the follow and update automatically.

## When you go over your plan's limit

If your plan changes and you have more collections than it allows, the extra collections become read-only. You can still view, export, import from, or delete them. Upgrading makes them editable again.

## Best practices

- Keep each collection focused on one purpose.
- Use the description for context, such as "Source for the weekly rotation".
- Mark favorites for the emotes you want Kao to prefer.
- Remove stale emotes so automation stays predictable.
