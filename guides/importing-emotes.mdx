## Overview

The **Import** page is the main place to add emotes to a server from the dashboard. You can search 7TV and FrankerFaceZ, browse 7TV users and emote sets, preview emotes at Discord size, and import one emote or many.

You can also import from Discord with [`/kao`](/guides/bot-commands) or from your browser with the [Kao browser extension](/guides/browser-extension).

## Before you begin

- Kao must be in the target server. See the [Quickstart](/quickstart).
- The bot needs the **Create Expressions** permission.
- The server needs free static or animated emoji slots.

## Search for emotes

1. Open **Import**.
2. Select the target server.
3. Type a search term, or leave the search empty to see trending emotes.
4. Open **Filters** to narrow the results.
5. Select an emote to preview it.

| Filter | Options |
|--------|---------|
| **Source** | **7TV** or **FrankerFaceZ** |
| **Trending** | **Today**, **This Week**, **This Month**, **All Time**, or **New Uploads**. FrankerFaceZ supports **All Time** and **New Uploads** |
| **Type** | **All Emotes**, **Animated Only**, or **Static Only**. FrankerFaceZ supports **All Emotes** only |

You can also paste a 7TV emote link or ID, or a FrankerFaceZ emote link or ID, into the search box.

### Search 7TV by tag

When **Source** is 7TV and you are on the **Emotes** tab, you can search by 7TV tag.

1. Type `#` followed by a tag, such as `#cat`.
2. Press Space or Enter. The tag becomes a pill under the search bar.
3. Add more tags, or combine tags with a name. For example, `dance #cat #hat` finds emotes named "dance" that have both tags.

If you type a single word without `#`, Kao offers **Add tag #word** to turn it into a tag. To remove a tag, click its pill.

- You can search up to 10 tags at once.
- Tags can use up to 30 letters, numbers, or underscores, with no spaces.
- Tag searches sort by **All Time** unless you choose a different sort in **Filters**.
- Switching to FrankerFaceZ or the **Users** tab clears your tags.

<Info>
Kao can no longer search BetterTTV or EmojiGG because those providers closed their search to other sites. BetterTTV and EmojiGG emotes you already saved in Kao still import.
</Info>

## Browse 7TV users and sets

1. Switch to the **Users** tab. It is available when **Source** is 7TV.
2. Search for a 7TV user and open their profile.
3. Open one of their **Emote Sets**.
4. Use **Filter emotes…** to search within the set.
5. Select the emotes you want.

Search and the animated or static filter cover the whole set, not just the page you are on.

## Import a single emote

1. Select an emote to open its details.
2. Check the Discord-size previews.
3. Edit the emoji name if needed.
4. Click **Add to Server**.

Emoji names must be 2 to 32 characters long. They can contain letters, numbers, and underscores, and cannot start with a number. Kao replaces spaces, dashes, and dots with underscores.

<Warning>
If some emotes in your import have the same name as emojis already in the server, Kao shows **Duplicate Names Found**. Choose **Skip Duplicates** to leave those emotes out, or **Import All** to import them anyway. To avoid confusion, rename the new emote first.
</Warning>

## Choose appearance and framing

Kao offers two controls for how an emote fits into Discord's square emoji.

| Control | Option | Result |
|---------|--------|--------|
| **Appearance** | **Auto** | The recommended balance between subject size and empty space |
| **Appearance** | **Larger** | Makes the subject fill more of the emoji. Takes effect only with **Trim** |
| **Framing** | **Fit** | Shows the whole image |
| **Framing** | **Trim** | Removes empty space around the subject |

The default is **Auto** with **Fit**. **Larger** with **Trim** can crop wide emotes, and Kao warns you when it will. Check the Discord-size previews before you import.

For a batch, select emotes and apply a choice to all of them. A choice you make for one emote overrides the batch choice.

### Set your import defaults

To change the starting choice for new imports, open **Settings** and go to **Import defaults**. Your defaults apply to new imports, **Quick add**, collection imports, the Emote Creator, and setup.

## Import a batch

1. Select several emotes. The selection bar shows how many will fit in the server.
2. Review the selection and target server.
3. Click the import button in the selection bar.

If you select more emotes than the server or your plan allows, Kao plans the batch from the emotes that fit. If upgrading would not raise the limit, Kao offers **Import the first N now**.

You can minimize the import and keep using Kao. Follow it from:

- The import progress window
- The operations dock at the bottom of the dashboard
- **Activity**

## How long imports take

Discord lets each server take about 50 new emojis an hour. This limit is shared by Kao imports, rotations, restores, and manual uploads. When a server reaches it, Kao queues the rest and shows "Waiting for Discord's hourly emoji limit" with an estimated finish time. The estimate updates every minute.

Your plan also sets how many emotes you can add per day. See **Usage and limits** on the **Activity** page.

Some animated emotes need extra preparation. Kao may move them to background processing while you keep using the dashboard. They import automatically when processing finishes.

## Animated emotes

Kao fits animated emotes under Discord's 256 KB limit and keeps every frame. Kao may upload them as animated WebP or AVIF. If Kao cannot keep every frame within the limit, it tells you why instead of uploading a broken emote.

## Check that an import finished

An import is complete when **Activity** shows a final result and the emoji appears in the server.

- **Activity** shows the batch as finished rather than waiting or running.
- The result separates added, failed, and still-waiting emotes.
- The emoji appears on the **Emotes** page for that server.

If a batch partly fails, fix the reported cause before you import the failed emotes again.

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| Server is full | No free static or animated slots | Delete unused emojis or choose another server |
| Invalid emoji name | The name has unsupported characters or starts with a number | Use letters, numbers, and underscores |
| "Bot is missing Create Expressions" | The bot's role lacks the permission | Use **Update in Discord** on the server's page, or fix the role |
| BetterTTV or EmojiGG search fails | Kao no longer searches these sources | Search 7TV or FrankerFaceZ instead |
| Import is waiting | Discord's hourly limit or your daily allowance was reached | Wait for the estimated time shown in **Activity** |
| Wide emote is cropped | **Larger** with **Trim** is selected | Choose **Fit** or **Auto** |
| FrankerFaceZ results are slow | FrankerFaceZ responds slowly | Wait, or search 7TV |
