## Overview

Kao imports emotes from 7TV, BetterTTV, FrankerFaceZ, and EmojiGG into your Discord server through a web dashboard. Use the hosted Kao Bot or Bring Your Own Bot. The **Import** page is the main place to add emotes. You can search supported platforms, browse 7TV sets, paste Discord emote text, preview results, and import one or more emotes.

Kao supports:

- 7TV
- BetterTTV
- FrankerFaceZ
- EmojiGG
- Discord emote text or URLs pasted into the import tool

Use this guide when you want the imported emoji to become a real Discord server
emoji. The bot needs permission and the server needs an available static or
animated slot. A queued or optimizing state is progress, not proof of delivery.

## Before you begin

Follow the [quickstart](/quickstart) to connect the hosted Kao Bot or your BYOB bot first. Then make sure:

- The target server appears in the server picker.
- The hosted Kao Bot or your BYOB bot is installed in that server.
- The bot has **Manage Emojis and Stickers** permission.
- The server has enough static or animated emoji slots.

## Search for emotes

1. Open **Import** in the dashboard.
2. Select the target server.
3. Enter a search term.
4. Use filters to narrow results by source, sort order, or animation type.
5. Open an emote to preview it before importing.

Search works best with short emote names, creator names, or common community phrases.

## Import a single emote

1. Open an emote result.
2. Review the preview.
3. Edit the emoji name if needed.
4. Choose **Import**.

Discord emoji names must be 2 to 32 characters and can contain letters, numbers, and underscores.

<Warning>
If the import name already exists on the server, rename the new emote or remove the existing emoji first.
</Warning>

## Choose appearance and framing

When you select emotes for import, use the appearance controls to decide how the source image is fitted into a Discord emoji.

| Option | Result |
|---------|-------------|
| Auto | Uses the recommended balance between subject size and empty space |
| Larger | Makes the subject bigger; wide emotes may be cropped |
| Fit | Shows the entire image |
| Trim | Removes more empty space around the subject |

For a batch, select a group of emotes, choose a profile, and apply it to the selected items. You can reset custom choices when you want to return to the batch setting.

Review the **Discord-scale preview** before importing. Check both the **Message** and **Picker** previews when an emote has important edges or fine detail.

## Import from pasted Discord emotes

Use the Discord import option when you already have emotes in a message or URL list.

1. Open the Discord import tool from the **Import** page.
2. Paste Discord emote text, emote URLs, or message text containing emotes.
3. Review the parsed emotes.
4. Remove anything you do not want.
5. Import the remaining emotes to your selected server.

## Browse 7TV users and sets

When a 7TV user or set appears in search:

1. Open the profile or set.
2. Browse the available emotes.
3. Filter within the set if needed.
4. Import individual emotes or select several for a batch.

## Importing batches

Select several emotes, review the selected items and target server, then choose **Import**. Kao shows progress for each emoji.

Completion time depends on file processing, your available plan allowance, and Discord limits. A queued batch can take longer than a few minutes. Wait for the final result rather than treating the start of a batch as a successful import.

Difficult animated emotes may show as optimizing while Kao prepares a Discord-sized file. Progress stays visible while that preparation finishes.

If background optimization is still running, Kao imports the emote automatically when processing finishes. You can minimize the import window and continue browsing, then follow the result from **Activity**.

If you select more emotes than the target server can currently fit, Kao plans the batch from the emotes that have available static or animated slots. Plan batch limits and upgrade prompts use that planned import count, not every selected search result.

You can monitor batch progress from:

- The import progress modal
- The operations dock at the bottom of the dashboard
- The **Activity** page

<Info>
Check **Activity** to see why work is waiting. Rate limits can clear with time, but a full server needs free emoji slots. Fix missing permissions before retrying failed work.
</Info>

## Animated GIF and WebP emotes

Kao can process animated provider emotes, including GIF and animated WebP sources. The source format and the file uploaded to Discord can differ because Kao prepares the image for Discord. Check the animated preview and the server's available animated emoji slots before importing.

Some animations need background optimization. An optimizing status means the image is still being prepared; check **Activity** for the final import result.

## How to know the import finished

An import is complete only when the batch reports its final result and the emoji
appears in the target Discord server. Check:

- **Activity** shows the batch as complete rather than queued or optimizing.
- The final result separates imported, failed, and still-waiting items.
- The emoji appears in the target server's emoji list.
- Failed items have enough capacity and the bot still has permission before you retry.

If a batch partially completes, retry only the failed items after fixing the
reported cause.

## File checks

Before uploading, Kao checks that imported files are usable Discord emoji images. Kao only accepts supported CDN/storage sources and validates image type, size, and hash before upload, so unsupported hosts, invalid image files, and oversized images are rejected early.

## Troubleshooting

| Problem | What to try |
|---------|-------------|
| Server is at capacity | Delete unused emojis or choose a server with free slots |
| Invalid emoji name | Use only letters, numbers, and underscores |
| Bot missing permissions | Reinvite or update the bot role with Manage Emojis and Stickers |
| Source unavailable | Try again later or choose a different source |
| Animated emote will not import | Check animated emoji capacity and source file size |
| Preview is still preparing | Wait for processing to finish, then review the Discord-scale preview |
| Larger crops the emote | Choose **Fit** or **Auto**, or review the exact preview before importing |
| Import is queued | Check **Activity** for the quota, capacity, or Discord limit that is delaying it |
