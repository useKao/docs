## Overview

Type `/kao` in any channel to open Kao's home for that server. From there you can see free emoji slots and running work, add and manage emotes, follow streamers, and run polls without opening a browser.

Kao's Discord commands work with both the hosted Kao Bot and BYOB bots.

## Before you begin

- Kao must be in the server. See the [Quickstart](/quickstart).
- You need a Kao role in the server, plus the matching Discord permission. The server owner and Administrators always have access. See [Kao roles](/guides/server-settings#kao-roles).

## Commands

| Command | What it does |
|---------|--------------|
| `/kao` | Opens Kao's home for the server |
| `/emotes [search]` | Opens **Manage emotes**, optionally filtered by a search |
| `/import <query>` | Adds emotes from a link, a set, a streamer's name, or search words |
| `/settings` | Opens Kao's settings for the server |
| `/activity` | Shows recent Kao work in the server |
| **Import emotes** | Message command. Adds the emotes from a message |
| **Start an emote poll** | Message command. Starts a poll from the emotes in a message |

To use a message command, right-click a message (or long-press it on mobile), then choose **Apps**.

## The /kao home

The home card shows the server's free slots, running work, and anything that needs attention. Each panel has **Back** and **Home** buttons.

| Panel | Use it to |
|-------|-----------|
| **Add emotes** | Import emotes into the server |
| **Manage emotes** | Search, rename, protect, restrict, download, or delete emotes |
| **7TV channels** | Follow streamers and get their new 7TV emotes |
| **More** | Open **Collections**, **Backups**, **Rotations**, **Polls**, **Health**, **Activity**, and **Settings** |

**Health** checks for missing permissions, nearly full slots, duplicates, and old backups. Each problem has a **Fix** button.

## Add emotes from Discord

You can add emotes from:

- A 7TV or FrankerFaceZ emote link
- A 7TV emote set
- A streamer's name
- Search words
- Discord emojis or image attachments in a message, with the **Import emotes** message command

Every import opens a review card first. Nothing changes until you confirm.

After you confirm, the card updates as the import runs. Once the import finishes, you have 10 minutes to click **Undo**. You can also undo it from **Activity** on the dashboard during the same 10 minutes.

<Info>
Undo is available for imports only. Deleted emojis cannot be undone from Discord. Create a backup before large deletions.
</Info>

## Manage emotes from Discord

Use `/emotes` or `/kao` > **Manage emotes**.

1. Search by name, or filter to **Static**, **Animated**, **Protected**, or **Locked to roles**.
2. Select an emote.
3. Choose **Rename**, **Protect** or **Unprotect**, a role limit, **Download**, or **Delete**.

For bulk cleanup, use **Delete several**, **Find duplicates**, or **Delete newest**. Kao shows a **Review deletion** step before anything is deleted, then reports what happened to each emote.

Members only see the actions their Kao role allows.

## Language

Kao replies in the server's language by default. To change it, open **Commands** on the server's dashboard page and set **Server language**.

## Older commands on BYOB bots

BYOB bots still respond to some older commands, such as `/help`, `/status`, and `/emojis`. These now open the matching part of `/kao` or `/emotes`. Use `/kao` for new work. If `/kao` is not available on your bot, the older `/import url` command can upload directly without a review card or **Undo**.

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| `/kao` does not appear | Discord has not refreshed its command list, or the bot needs updated permissions | Restart Discord. On the server's **Overview**, use **Update in Discord** if it appears |
| "You need a Kao role to use Kao here." | You have no Kao role in the server | Ask a Kao administrator to assign you a role |
| An action is missing in **Manage emotes** | Your Kao role does not allow it | Ask for the **Emote manager** role |
| Import fails | The server is full, or the bot lacks **Create Expressions** | Free slots or fix permissions with **Health** |
| Kao says 7TV is having trouble | 7TV is unavailable | Wait and try again. Check [status.usekao.com](https://status.usekao.com) |
