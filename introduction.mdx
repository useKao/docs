## What is Kao?

Kao helps Discord server owners find, import, organize, and refresh custom emojis from one dashboard.

Use Kao when you want to:

- Import emotes from 7TV, BetterTTV, FrankerFaceZ, and EmojiGG
- Add or remove server emojis without downloading files manually
- Save emotes into collections for reuse
- Back up a server before making large emoji changes
- Rotate or sync emojis across one or more servers
- Let trusted teammates help manage emojis

## The fastest setup

Most servers should start with the hosted Kao Bot. You invite it once, then use the dashboard to import and manage emojis. You do not need to create a Discord application or handle a bot token.

Bring Your Own Bot is available for teams that need a custom bot name, avatar, status, or stronger separation between communities.

## Main workflows

| Workflow | What you use it for |
|----------|---------------------|
| Importing | Search emote platforms, paste Discord emote text, and add emojis to a server |
| Managing emojis | Rename, delete, filter, and review server emoji capacity |
| Collections | Save reusable sets of emotes for later imports, rotations, or sync groups |
| Backups | Snapshot a server's emojis before a risky change or restore them later |
| Rotations | Replace or refresh server emojis on a schedule |
| Sync groups | Keep one collection or server mirrored to other servers |
| Activity | Track running and past emoji operations |

## Supported emote sources

| Source | Static | Animated | Notes |
|--------|--------|----------|-------|
| 7TV | Yes | Yes | Supports user profiles and emote sets |
| BetterTTV | Yes | Yes | Good for Twitch community emotes |
| FrankerFaceZ | Yes | No | Static emotes only |
| EmojiGG | Yes | Yes | Searchable emoji catalog |

## Before you begin

You need:

- A Discord account
- A Discord server where you can manage the server or invite bots
- Permission for the bot to manage emojis and stickers in the target server
