## What is Kao?

Kao helps Discord server owners find, import, organize, and refresh custom emojis. You can work from the web dashboard at [usekao.com](https://usekao.com), from inside Discord with `/kao`, or from the Kao browser extension.

Use Kao when you want to:

- Import 7TV and FrankerFaceZ emotes without downloading files yourself
- Follow a streamer and get their new 7TV emotes in your server
- Let moderators add and manage emotes from Discord
- Let members vote on which emotes get added
- Protect emojis so Kao never removes them
- Back up, rotate, or sync emojis across one or more servers
- Make your own emotes with the Emote Creator

## The fastest setup

Most servers should start with the hosted Kao Bot. You invite it once, then use the dashboard or `/kao` to import and manage emojis. You do not need to create a Discord application or handle a bot token.

Bring Your Own Bot (BYOB) is for communities that want their own bot name, avatar, and status, or extra server features such as staff notifications and presets.

## Main workflows

| Workflow | What you use it for |
|----------|---------------------|
| Importing | Search 7TV and FrankerFaceZ and add emojis to a server |
| Kao in Discord | Add, manage, protect, and back up emotes with `/kao` |
| Emote polls | Let members vote on new emotes |
| Managing emojis | Rename, protect, delete, and review emoji slots |
| Collections | Save reusable sets of emotes |
| Streamer emotes | Follow a streamer's 7TV emote set |
| Backups | Save a server's emojis and restore them later |
| Rotations | Refresh server emojis on a schedule |
| Sync groups | Make other servers match a collection or source server |
| Emote Creator | Combine emotes and overlays into new emotes |
| Activity | Track running and past emoji work |

## Supported emote sources

| Source | Search in Kao | Static | Animated | Notes |
|--------|---------------|--------|----------|-------|
| 7TV | Yes | Yes | Yes | Search emotes, users, and emote sets. Paste a 7TV emote link or ID. |
| FrankerFaceZ | Yes | Yes | Yes | Paste an FFZ emote link or ID. Results can load more slowly. |
| BetterTTV | No | Yes | Yes | Search is no longer available. Emotes you already saved in Kao still import. |
| EmojiGG | No | Yes | Yes | Search is no longer available. Emotes you already saved in Kao still import. |

<Info>
BetterTTV and EmojiGG closed their search to other sites, so Kao can no longer search them. Emotes you saved from them before, for example in a collection, still import.
</Info>

In Discord, `/kao` and the **Import emotes** message command can also add Discord emojis from a message and image attachments. See [Use Kao in Discord](/guides/bot-commands).

## Before you begin

You need:

- A Discord account
- A Discord server where you have the **Manage Server** permission, or a server admin who can invite Kao for you
