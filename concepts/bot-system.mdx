## Overview

Kao needs a Discord bot in each server it manages. You can invite Kao's hosted bot or connect your own. Most servers should use the hosted Kao Bot.

| Setup | Best for | What you manage |
|-------|----------|-----------------|
| Hosted Kao Bot | Most servers and the fastest setup | Approving the Discord invite |
| Bring Your Own Bot (BYOB) | Your own bot name, avatar, and status, or extra server features | A Discord application, its token, and its invites |

You can use both in the same Kao account.

## What each setup supports

| Feature | Hosted Kao Bot | BYOB |
|---------|----------------|------|
| Dashboard imports, emoji management, and protection | Yes | Yes |
| `/kao` and other Discord commands | Yes | Yes |
| Backups, rotations, syncs, and streamer follows | Yes | Yes |
| Emote polls | Yes | Yes |
| Team sharing with a Discord role | Yes (paid plans) | Yes (paid plans) |
| Staff notifications and community announcements | No | Yes |
| Server presets | No | Yes |
| Custom bot nickname | No | Yes (bot owner) |
| White-label branding and custom bot status | No | Pro or Enterprise (bot owner) |

## Hosted Kao Bot

Kao runs the hosted Kao Bot for you. There is no token to store or bot to keep online.

To add the hosted Kao Bot to a server:

1. Open **Servers** and click **Add server**.
2. Choose **Use the Kao hosted bot**.
3. Choose the server, then click the invite button to open Discord.
4. Approve the invite in Discord.
5. Return to Kao. Kao verifies the installation automatically.

On the Free plan, the hosted Kao Bot can work in 2 servers. If you go over this limit, for example after a paid plan ends, Kao pauses the extra servers instead of removing them. Upgrading resumes them.

### One-time permission update

Servers that added Kao Bot before the late October 2026 update need to approve updated permissions once. The server's **Overview** shows **Kao Bot needs a one-time permission update** with an **Update in Discord** button. Approving it requires the server owner or a member with **Manage Server**. Kao never asks for Administrator.

## Bring Your Own Bot

Use BYOB when you want your own bot identity or the BYOB-only server features listed above.

### Create a BYOB bot

1. Open the [Discord Developer Portal](https://discord.com/developers/applications) and create an application.
2. Open **Bot**. Under **Privileged Gateway Intents**, turn on **Server Members Intent**.
3. Click **Reset Token** and copy the new token.
4. In Kao, open **Servers**, click **Add server**, and choose **Connect your own bot**.
5. Paste the token and let Kao check it.
6. Invite the bot to each server you want Kao to manage.

<Warning>
Kao requires **Server Members Intent**. Without it, Discord refuses the bot's connection. Kao uses it to check which members are allowed to use your bot.
</Warning>

<Warning>
Treat a bot token like a password. Only paste it into Kao's token field. If it is ever exposed, reset it in Discord and update it in Kao.
</Warning>

On the Free plan, you can connect 1 bot in up to 3 servers. See [Billing and plans](/guides/billing#plan-limits).

## Discord permissions

Kao asks Discord for these bot permissions:

| Permission | Why Kao needs it |
|------------|------------------|
| **Create Expressions** | Add new emojis |
| **Manage Expressions** | Rename, restrict, and delete emojis |
| **View Channels**, **Send Messages**, **Embed Links**, **Read Message History** | Reply to commands and post digests, polls, and notices |
| **Use External Emojis** | Show emotes in Kao's Discord messages |
| **Use Application Commands** | Run `/kao` and other commands |
| **Change Nickname** | Apply a bot nickname |
| **Manage Webhooks** | Post community announcements |

Kao never asks for Administrator.

## Bot health warnings

Kao warns you on **Overview**, **Servers**, and the server's page when:

- The bot is missing a Discord permission.
- The bot is offline or still starting, so Kao cannot check it.
- The bot is no longer in the server.

Open the warning to see what is affected. Use the offered action, such as **Update in Discord** or **Invite again**, then let Kao check again.

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| Server is not in the invite list | Your Discord account lacks **Manage Server** there | Ask a server admin for the permission or to invite Kao |
| Hosted bot did not verify | The Discord invite was not completed | Click **Reopen Discord**, approve the invite, then return to Kao |
| BYOB token is rejected | The token was reset or copied incorrectly | Reset the token in Discord and paste the new one |
| BYOB bot will not connect | **Server Members Intent** is off | Turn it on in the Developer Portal under **Bot** |
| Bot cannot add emojis | The bot is missing **Create Expressions** | Use **Update in Discord**, or give the bot's role the permission |
| Server shows under **Needs attention** | The bot was removed from the server | Click **Invite again** |
